# On-device checklist

Run on a real iPhone and a real Android phone (plus a tablet where noted) before release.

- [ ] Scan a dark card and a tilted card: edges detected, fields filled correctly
- [ ] Scan a Hindi card: Devanagari renders (no boxes) and is kept exactly as printed
- [ ] No network: Gemini error shown, retry works once back online
- [ ] Airplane mode: "Fill manually" saves the contact with photos
- [ ] Discard on review: no leftover photos in app storage
- [ ] Tablet landscape: home stack, list view and contact detail lay out properly
- [ ] Landscape on phone: list view scrolls, nothing clipped
- [ ] Old / low-end Android: deck swipe and list scrolling stay smooth
- [ ] Contact card flip works on Android (no mirrored or blank side)
- [ ] Small Android phone: keyboard does not cover fields on review / settings
- [ ] Reduce motion on (iOS and Android): no rotation/slide, fades only
- [ ] App icon (iOS, Android adaptive + themed) and splash look right
